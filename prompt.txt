## ৩. ডকুমেন্ট স্ট্রাকচার বিশ্লেষণ

### ৩.১ ডকুমেন্টের পেজ লেআউট

DOCX ফাইলটি **Landscape A4** ফরম্যাটে তৈরি (width: 16839 DXA, height: 11907 DXA)। মার্জিন সকল দিক থেকে 720 DXA (0.5 ইঞ্চি)।

**ডকুমেন্টে মোট পেজ টাইপ: ৪টি**

| পেজ টাইপ | বর্ণনা | সংখ্যা |
|---|---|---|
| **Type 1** | শিরোনাম + প্রথম ডেটা টেবিল | ১টি (সবার শুরুতে, শুধুমাত্র একবার) |
| **Type 2** | মাঝামাঝি ডেটা টেবিল | এন্ট্রির সংখ্যার উপর নির্ভর করে, একাধিকবার |
| **Type 3** | শেষ ডেটা টেবিল + মোট সারি | ১টি (সব ডেটা টেবিলের শেষে, শুধুমাত্র একবার) |
| **Type 4** | সারসংক্ষেপ/স্ট্যাটিস্টিক্স টেবিল | ১টি (সবার শেষে, শুধুমাত্র একবার) |

### ৩.২ পেজ ক্যাপাসিটি

- **Type 1 পেজ:** ৩টি এন্ট্রি ধারণ করে
- **Type 2 পেজ:** ৪টি এন্ট্রি ধারণ করে (এটিই বারবার রিপ্লিকেট হয়)
- **Type 3 পেজ:** ৩-৪টি এন্ট্রি + ১টি "মোট=" সারি
- **Type 4 পেজ:** শুধু স্ট্যাটিস্টিক্স (কোনো এন্ট্রি নেই)

**গুরুত্বপূর্ণ:** Type 3 এবং Type 4 পেজের মাঝে একটি অতিরিক্ত খালি ডেটা টেবিল থাকে (Type 2 কাঠামোয়, কিন্তু খালি)। এটি টেম্পলেটের অংশ এবং সবসময় যুক্ত থাকতে হবে।

### ৩.৩ এন্ট্রি বিতরণ উদাহরণ

২৪টি এন্ট্রির জন্য:
- Type 1 পেজ: এন্ট্রি ০১–০৩ (৩টি)
- Type 2 পেজ ×৫: এন্ট্রি ০৪–০৭, ০৮–১১, ১২–১৫, ১৬–১৯, ২০–২৩ (প্রতিটিতে ৪টি)
- Type 3 পেজ: এন্ট্রি ২৪ (১টি) + মোট সারি
- খালি Type 2 পেজ (১টি)
- Type 4 সারসংক্ষেপ পেজ

### ৩.৪ ফন্ট ও এনকোডিং

- **ফন্ট:** `SutonnyMJ` (সকল টেক্সটে একই ফন্ট ব্যবহার করা হয়)
- **এনকোডিং:** বিজয় (Bijoy) — ডকুমেন্টে সব বাংলা টেক্সট বিজয় এনকোডিংয়ে সংরক্ষিত
- **কারণ:** `SutonnyMJ` ফন্ট ASCII কোড পয়েন্ট ব্যবহার করে বাংলা গ্লিফ রেন্ডার করে। ইউনিকোড বাংলা সরাসরি ব্যবহার করলে ডকুমেন্টে ভুল অক্ষর দেখাবে।

### ৪.১ মোট সারি (Type 3 পেজের শেষে)

মোট সারিতে কলাম ৩-এ `‡gvU=` লেখা থাকে এবং নিম্নলিখিত ফিল্ডে সমষ্টি দেওয়া হয়:
- কলাম ৬: মোট কিলোমিটার + `wK:wg:` suffix
- কলাম ৭: মোট লিটার + `wjUvi` suffix  
- কলাম ৮: মোট জ্বালানি খরচ (টাকা) + `/-` suffix
- কলাম ৯: মোট মোবাইল খরচ (টাকা) + `/-` suffix
- কলাম ১০: মোট DA (টাকা) + `/-` suffix
- কলাম ১১: গ্র্যান্ড টোটাল (টাকা) + `/` suffix

## ৬. সারসংক্ষেপ টেবিল স্ট্রাকচার (Type 4 পেজ)

এই টেবিলে দুটি কলাম আছে, বাম ও ডান, প্রতিটিতে ৬টি সারি:

**বাম অংশ (কাউন্টিং ডেটা):**

| ক্ষেত্র | মান |
|---|---|
| `মোট ট্যুরের সংখ্যা:` | `[N] টি` |
| `শুক্রবার ট্যুর করলে তার সংখ্যা:` | `নাই` বা `[N] টি` |
| `মাসিক মিটিং এর সংখ্যা:` | `[N] টি` |
| `ম্যানেজার সাহেব বা অন্য কারো সাথে গেলে তার সংখ্যা:` | `[N] টি` |
| `৫০ কিলোমিটারের কম ট্যুরের সংখ্যা:` | `[N] টি` |
| `হিসাবান্তে মোট ট্যুরের সংখ্যা:` | `[N] টি` |

**ডান অংশ (আর্থিক সারসংক্ষেপ):**

| ক্ষেত্র | মান |
|---|---|
| `মোট তেলের পরিমাণ:` | `[N] লিটার` |

| `টোটাল তেল বাবদ এক্সপেন্স অ্যামাউন্ট:` | `[N] টাকা` |
| `টোটাল মোবাইল ডাউন অ্যামাউন্ট:` | `[N] টাকা` |

| `মোট অ্যামাউন্ট(সকল বিল):` | `[N] টাকা` |

### ৬.১ "হিসাবান্তে মোট ট্যুরের সংখ্যা" গণনা

```
হিসাবান্তে = মোট ট্যুর - শুক্রবার ট্যুর - মাসিক মিটিং
```

উদাহরণ: ২৪ ট্যুর - ০ শুক্রবার - ১ মিটিং = ২৩ হিসাবান্তে

## ৭. এন্ট্রি ক্যাটাগরি ও ব্যবসায়িক নিয়ম

### ৭.১ সাধারণ ভিজিট এন্ট্রি (Regular Tour)

একটি সাধারণ দিনে:
- **পরিবেশকের নাম:** একাধিক দোকানের নাম বাংলায়, প্রতিটি নামের শেষে `│` চিহ্ন দিয়ে আলাদা করা
  - প্রতিটি নামের শুরুতে `মেসার্স ` (বিজয় এনকোডিং: `‡gmvm© `) লেখা থাকে
  - উদাহরণ: `মেসার্স মা বাবার দোয়া ট্রেডার্স│ মেসার্স শান্তি কৃষি ভান্ডার│`
- **মিটার রিডিং:** শুরু এবং শেষ (পূর্ববর্তী এন্ট্রির শেষ রিডিং = পরবর্তী এন্ট্রির শুরু রিডিং)
- **জ্বালানি:** লিটার সংখ্যা এবং মূল্য (যদি সেদিন পেট্রোল কেনা হয়)
- **DA:** ২০০/- (সর্বদা, মাসিক মিটিং ছাড়া)
- **মোবাইল রিচার্জ:** যদি সেদিন রিচার্জ করা হয়

### ৭.২ এন্ট্রি টাইপ

এই সিস্টেমে ৩ ধরনের এন্ট্রি আছে:

**ধরন A: শুধু DA** (সবচেয়ে সাধারণ)
- পরিবেশক নাম ✓, মিটার রিডিং ✓, DA = ২০০/-, পেট্রোল = না, মোবাইল = না
- মোট খরচ = ২০০/-

**ধরন B: DA + পেট্রোল**
- পরিবেশক নাম ✓, মিটার রিডিং ✓, DA = ২০০/-, পেট্রোল = লিটার × মূল্য
- মোট খরচ = ২০০/- + পেট্রোল খরচ

**ধরন C: DA + পেট্রোল + মোবাইল রিচার্জ**
- পরিবেশক নাম ✓, মিটার রিডিং ✓, DA = ২০০/-, পেট্রোল + মোবাইল
- মোট খরচ = ২০০/- + পেট্রোল + মোবাইল

**ধরন D: DA + মোবাইল রিচার্জ (পেট্রোল ছাড়া)**
- পরিবেশক নাম ✓, মিটার রিডিং ✓, DA = ২০০/-, মোবাইল রিচার্জ
- মোট খরচ = ২০০/- + মোবাইল

**ধরন E: সার্ভিস সেন্টার / মাসিক মিটিং** (বিশেষ)
- এন্ট্রির বিশেষ বৈশিষ্ট্য:
  - কলাম ৩-এ ভেন্যুর নাম (যেমন: `রংপুর সেলস সেন্টার│ ডোমার হইতে রংপুর সেলস সেন্টার বাস ও অটোতে যাতায়াত ভাড়া=460/-`)
  - মিটার রিডিং: শুরু এবং শেষ একই (০০ কিলোমিটার, কারণ মোটর সাইকেল ব্যবহার হয়নি)
  - পেট্রোল = না
  - DA = না (০/-)
  - পরিবহন ভাড়া → কলাম ১১ (মোট খরচ)-এ সরাসরি যোগ হয়
  - কলাম ১২-এ `মাসিক মিটিং` লেখা থাকে
  - এই এন্ট্রি সারসংক্ষেপে "মাসিক মিটিং এর সংখ্যা" কাউন্টারে যোগ হয়

### ৭.৩ পরিবহন ভাড়া সম্পর্কিত ব্যাখ্যা

ডকুমেন্টে entry 15 (18/05/26) দেখে:
```
রংপুর সেলস সেন্টার│
ডোমার হইতে রংপুর সেলস সেন্টার বাস ও অটোতে যাতায়াত ভাড়া=460/-
```
- মিটার রিডিং শুরু = ৫৩০৯৫, শেষ = ৫৩০৯৫ (কোনো পরিবর্তন নেই)
- মোট কিলোমিটার = ০০
- DA = শূন্য
- পেট্রোল = শূন্য
- মোট খরচ = ৪৬০/- (পরিবহন ভাড়া)
- "অন্য কারো সাথে" কলামে: `মাসিক মিটিং`

### ৭.৪ মোবাইল রিচার্জ কলাম ব্যবহার

Entry 01 (02/05/26) তে: ১০ লিটার পেট্রোল @ ১৩৫.৭ = ১৩৫৭/-, মোবাইল = ৫৬০/-
মোট = ১৩৫৭ + ৫৬০ + ২০০ = ২১১৭/-

Entry 12 (14/05/26) তে: মোবাইল = ৫৬০/-, DA = ২০০/-
মোট = ৫৬০ + ২০০ = ৭৬০/- (পেট্রোল নেই সেদিন)

## ৮. স্বয়ংক্রিয় গণনা

### ৮.১ প্রতিটি এন্ট্রির জন্য

```python
# মোট কিলোমিটার
total_km = odometer_end - odometer_start

# জ্বালানি মূল্য
petrol_cost = round(petrol_liters * petrol_price_per_liter)

# মোট খরচ
if entry_type == 'MONTHLY_MEETING':
    total_cost = transport_fee  # শুধু পরিবহন ভাড়া
else:
    total_cost = petrol_cost + mobile_recharge + da_amount
    # da_amount সাধারণত 200
    # petrol_cost = 0 যদি সেদিন পেট্রোল না কেনা হয়
    # mobile_recharge = 0 যদি সেদিন রিচার্জ না করা হয়
```

### ৮.২ মাসিক সারসংক্ষেপের জন্য

```python
# মোট পরিসংখ্যান
total_tours = len(all_entries)
total_km_month = last_odometer - first_odometer  # সরাসরি মিটার রিডিং থেকে
total_liters = sum(e.petrol_liters for e in all_entries)
total_petrol_cost = sum(e.petrol_cost for e in all_entries)
total_mobile = sum(e.mobile_recharge for e in all_entries)
total_da = sum(e.da_amount for e in all_entries)
total_other = sum(e.transport_fee for e in all_entries)  # service center ভাড়া
grand_total = total_petrol_cost + total_mobile + total_da + total_other

# কাউন্টার
friday_tours = sum(1 for e in all_entries if e.date.weekday() == 4)
monthly_meetings = sum(1 for e in all_entries if e.entry_type == 'MONTHLY_MEETING')
manager_tours = sum(1 for e in all_entries if e.with_manager)
tours_under_50km = sum(1 for e in all_entries if e.total_km < 50 and e.entry_type == 'REGULAR')
net_tours = total_tours - friday_tours - monthly_meetings
```

```python
from bijoy import convert  # লাইব্রেরিভেদে ভিন্ন হতে পারে

def unicode_to_bijoy(unicode_text: str) -> str:
    """ইউনিকোড বাংলা → বিজয় এনকোডিং"""
    return convert(unicode_text)
```

**পদ্ধতি ২:** API ব্যবহার করুন:
- `https://api.bijoyconverter.com` বা অনুরূপ সার্ভিস

- Response: `{"bijoy": "evsjv †U·U"}`

**পদ্ধতি ৩:** নিজে ম্যাপিং টেবিল তৈরি করুন:

### ৯.৩ গুরুত্বপূর্ণ রূপান্তর নিয়ম

## ১০. কনফিগারেবল মান (Settings)

নিম্নলিখিত মানগুলো ব্যবহারকারী Telegram bot-এর মাধ্যমে পরিবর্তন করতে পারবেন:

| সেটিং | ডিফল্ট মান | বর্ণনা |
|---|---|---|
| `petrol_price_per_liter` | ১৩৫.৭০ টাকা | প্রতি লিটার পেট্রোলের দাম |

| `transport_fee_default` | — | সার্ভিস সেন্টার ট্রিপের পরিবহন ভাড়া (প্রতিবার জিজ্ঞেস করবে) |

এই সেটিংস প্রতি মাসে পরিবর্তন করা যাবে এবং ডেটাবেসে সংরক্ষিত থাকবে।

## ১১. ডেটাবেস স্কিমা (SQLite)

```sql
-- মাসিক কনফিগারেশন
CREATE TABLE monthly_config (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    month INTEGER NOT NULL,        -- 1-12
    year INTEGER NOT NULL,
    petrol_price REAL NOT NULL DEFAULT 135.70,
    da_amount INTEGER NOT NULL DEFAULT 200,
    mobile_recharge INTEGER NOT NULL DEFAULT 560,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    UNIQUE(month, year)
);

-- ট্যুর এন্ট্রি
CREATE TABLE tour_entries (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    month INTEGER NOT NULL,
    year INTEGER NOT NULL,
    entry_date DATE NOT NULL,
    serial_number INTEGER NOT NULL,  -- মাসের মধ্যে ক্রমিক নম্বর
    
    -- পরিবেশক তথ্য
    distributor_names TEXT NOT NULL,  -- JSON array of Bengali Unicode names
    
    -- মিটার রিডিং
    odometer_start INTEGER NOT NULL,
    odometer_end INTEGER NOT NULL,
    total_km INTEGER GENERATED ALWAYS AS (odometer_end - odometer_start) STORED,
    
    -- খরচ
    petrol_liters REAL DEFAULT 0,
    petrol_cost INTEGER DEFAULT 0,    -- Auto-calculated on save
    mobile_recharge INTEGER DEFAULT 0,
    da_amount INTEGER DEFAULT 200,
    transport_fee INTEGER DEFAULT 0,  -- Service center/meeting ট্রিপের জন্য
    total_cost INTEGER GENERATED ALWAYS AS (petrol_cost + mobile_recharge + da_amount + transport_fee) STORED,
    
    -- বিশেষ ক্ষেত্র
    entry_type TEXT DEFAULT 'REGULAR',  -- 'REGULAR' বা 'MONTHLY_MEETING'
    with_manager INTEGER DEFAULT 0,     -- 0 বা 1 (boolean)
    manager_designation TEXT,           -- যদি with_manager = 1
    notes TEXT,                         -- অতিরিক্ত নোট
    
    -- মেটাডেটা
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    
    FOREIGN KEY (month, year) REFERENCES monthly_config(month, year)
);

-- ইন্ডেক্স
CREATE INDEX idx_entries_month_year ON tour_entries(month, year);
CREATE INDEX idx_entries_date ON tour_entries(entry_date);
CREATE UNIQUE INDEX idx_entries_serial ON tour_entries(month, year, serial_number);

-- সেটিংস
CREATE TABLE settings (
    key TEXT PRIMARY KEY,
    value TEXT NOT NULL,
    updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);

-- রিপোর্ট লগ
CREATE TABLE generated_reports (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    month INTEGER NOT NULL,
    year INTEGER NOT NULL,
    file_path TEXT NOT NULL,
    generated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);
```

### ১৩.৩ DOCX এডিটিং পদ্ধতি

```python
import zipfile, shutil, os, copy, re
from lxml import etree

WORD_NS = 'http://schemas.openxmlformats.org/wordprocessingml/2006/main'

def generate_logsheet(month: int, year: int, entries: list, config: dict, template_path: str, output_path: str):
    """
    টেম্পলেট থেকে DOCX তৈরি করে।
    
    entries: list of dict with keys:
        - serial: int
        - date: datetime.date
        - distributor_names: list[str] (Unicode Bengali)
        - odometer_start: int
        - odometer_end: int
        - petrol_liters: float
        - petrol_cost: int
        - mobile_recharge: int
        - da_amount: int
        - transport_fee: int
        - total_cost: int
        - entry_type: 'REGULAR' | 'MONTHLY_MEETING'
        - manager_designation: str | None
    """
    
    # ১. টেম্পলেট কপি করুন
    shutil.copy(template_path, output_path)
    
    # ২. DOCX আনপ্যাক করুন (এটি একটি ZIP)
    work_dir = output_path + '_work'
    os.makedirs(work_dir, exist_ok=True)
    with zipfile.ZipFile(output_path, 'r') as z:
        z.extractall(work_dir)
    
    # ৩. document.xml পার্স করুন
    doc_path = os.path.join(work_dir, 'word', 'document.xml')
    tree = etree.parse(doc_path)
    root = tree.getroot()
    
    # ৪. হেডার আপডেট করুন (মাসের নাম, তারিখ)
    update_header(root, month, year)
    
    # ৫. ডেটা পেজ তৈরি করুন
    build_data_pages(root, entries, config)
    
    # ৬. সারসংক্ষেপ পেজ আপডেট করুন
    update_summary(root, entries, month, year)
    
    # ৭. XML সেভ করুন
    tree.write(doc_path, xml_declaration=True, encoding='UTF-8', standalone=True)
    
    # ৮. রিপ্যাক করুন
    with zipfile.ZipFile(output_path, 'w', zipfile.ZIP_DEFLATED) as z:
        for dirpath, _, filenames in os.walk(work_dir):
            for filename in filenames:
                filepath = os.path.join(dirpath, filename)
                arcname = os.path.relpath(filepath, work_dir)
                z.write(filepath, arcname)
    
    # ৯. ক্লিনআপ
    shutil.rmtree(work_dir)
```

### ১৩.৪ সেল টেক্সট প্রতিস্থাপন পদ্ধতি

```python
def set_cell_text(cell_element, bijoy_text: str):
    """
    একটি টেবিল সেলের টেক্সট প্রতিস্থাপন করে।
    বিদ্যমান ফরম্যাটিং (bold, font, size) অক্ষুণ্ণ রাখে।
    """
    W = WORD_NS
    
    # সেলের মধ্যে প্রথম paragraph খুঁজুন
    para = cell_element.find(f'.//{{{W}}}p')
    if para is None:
        return
    
    # বিদ্যমান run খুঁজুন (ফরম্যাটিং সংরক্ষণের জন্য)
    existing_run = para.find(f'{{{W}}}r')
    
    # সব existing runs মুছুন
    for r in para.findall(f'{{{W}}}r'):
        para.remove(r)
    
    if bijoy_text:
        # নতুন run তৈরি করুন, বিদ্যমান rPr কপি করুন
        new_run = copy.deepcopy(existing_run) if existing_run is not None else etree.SubElement(para, f'{{{W}}}r')
        
        # t element আপডেট করুন
        t_elem = new_run.find(f'{{{W}}}t')
        if t_elem is None:
            t_elem = etree.SubElement(new_run, f'{{{W}}}t')
        
        t_elem.text = bijoy_text
        if bijoy_text.startswith(' ') or bijoy_text.endswith(' '):
            t_elem.set('{http://www.w3.org/XML/1998/namespace}space', 'preserve')
        
        para.append(new_run)
```

```python
def build_data_pages(root, entries: list, config: dict):
    """
    এন্ট্রির সংখ্যার উপর ভিত্তি করে ডেটা টেবিল তৈরি করে।
    
    পেজ ক্যাপাসিটি:
    - পেজ ১ (Type 1): ৩ এন্ট্রি
    - পেজ ২+ (Type 2): ৪ এন্ট্রি প্রতিটি
    - শেষ পেজ (Type 3): বাকি এন্ট্রি + মোট সারি
    - অতিরিক্ত খালি পেজ (Type 2 কাঠামো)
    
    পদ্ধতি:
    ১. টেম্পলেট থেকে Type 2 টেবিল (মাঝামাঝি পেজ) কপি করুন
    ২. যতটা প্রয়োজন ততটা টেবিল যোগ করুন
    ৩. Type 3 (শেষ) টেবিল আপডেট করুন
    """
    
    # টেম্পলেট থেকে ৪টি ডেটা টেবিল চিহ্নিত করুন
    # (µwgK bs সংবলিত টেবিলগুলো)
    W = WORD_NS
    body = root.find(f'{{{W}}}body')
    tables = body.findall(f'{{{W}}}tbl')
    
    # DATA টেবিল = যেগুলোতে 'µwgK bs' হেডার আছে
    data_tables = [t for t in tables if is_data_table(t)]
    
    PAGE1_ROWS = 3   # Type 1: ৩ এন্ট্রি
    MIDDLE_ROWS = 4  # Type 2: ৪ এন্ট্রি
    
    total_entries = len(entries)
    
    # পেজ ১ → প্রথম ৩ এন্ট্রি
    fill_data_table(data_tables[0], entries[0:3])
    
    if total_entries <= 3:
        # শুধু পেজ ১ যথেষ্ট, Type 3 (শেষ টেবিল) খালি রাখুন
        # মোট সারি পেজ ৩-এ যোগ করুন
        add_total_row(data_tables[2], entries, config)
        return
    
    # মাঝামাঝি পেজের প্রয়োজনীয় সংখ্যা গণনা
    remaining = total_entries - 3
    full_middle_pages = (remaining - 1) // MIDDLE_ROWS  # শেষ পেজ বাদে
    last_page_entries = remaining - full_middle_pages * MIDDLE_ROWS
    
    # Type 2 টেবিলের রেফারেন্স কপি করুন
    middle_table_template = copy.deepcopy(data_tables[1])
    last_data_table_template = copy.deepcopy(data_tables[2])
    
    # বিদ্যমান টেবিলের পর নতুন টেবিল ঢোকান
    entry_idx = 3
    
    for page_idx in range(full_middle_pages):
        new_table = copy.deepcopy(middle_table_template)
        fill_data_table(new_table, entries[entry_idx:entry_idx + MIDDLE_ROWS])
        entry_idx += MIDDLE_ROWS
        insert_table_after(body, data_tables[1], new_table)
    
    # শেষ ডেটা পেজ (Type 3 স্ট্রাকচার, মোট সারিসহ)
    last_table = copy.deepcopy(last_data_table_template)
    fill_data_table(last_table, entries[entry_idx:])
    add_total_row(last_table, entries, config)
    # টেম্পলেটের Type 3 টেবিল প্রতিস্থাপন করুন
    replace_table(body, data_tables[2], last_table)
```

def fill_entry_row(row_element, entry: dict):
    """
    একটি টেবিল সারিতে এন্ট্রির ডেটা পূরণ করে।
    কলামের ক্রম অনুসরণ করুন।
    """
    cells = row_element.findall(f'.//{{{WORD_NS}}}tc')
    
    # কলাম ম্যাপিং (0-indexed)
    COL_SERIAL = 0          # ক্রমিক নম্বর (01, 02...)
    COL_DATE = 1            # তারিখ (DD/MM/YY)
    COL_DISTRIBUTOR = 2     # পরিবেশকের নাম (Bijoy)
    COL_ODO_START = 3       # মিটার শুরু
    COL_ODO_END = 4         # মিটার শেষ
    COL_TOTAL_KM = 5        # মোট কিমি
    COL_LITERS = 6          # লিটার
    COL_PETROL_COST = 7     # পেট্রোল মূল্য
    COL_MOBILE = 8          # মোবাইল
    COL_DA = 9              # DA
    COL_TOTAL = 10          # মোট
    COL_WITH = 11           # সাথে
    
    # সিরিয়াল নম্বর
    set_cell_text(cells[COL_SERIAL], f"{entry['serial']:02d}")
    
    # তারিখ (DD/MM/YY ফরম্যাট)
    d = entry['date']
    set_cell_text(cells[COL_DATE], f"{d.day:02d}/{d.month:02d}/{str(d.year)[2:]}")
    
    # পরিবেশকের নাম (বিজয়তে রূপান্তরিত)
    distributor_text = format_distributor_names(entry['distributor_names'], entry)
    set_cell_text(cells[COL_DISTRIBUTOR], distributor_text)
    
    # মিটার রিডিং
    set_cell_text(cells[COL_ODO_START], str(entry['odometer_start']))
    set_cell_text(cells[COL_ODO_END], str(entry['odometer_end']))
    
    # মোট কিমি
    km = entry['odometer_end'] - entry['odometer_start']
    set_cell_text(cells[COL_TOTAL_KM], f"{km:02d}" if km == 0 else str(km))
    
    # পেট্রোল
    if entry['petrol_liters'] > 0:
        set_cell_text_multiline(cells[COL_LITERS], [
            str(int(entry['petrol_liters'])),
            unicode_to_bijoy('লিটার')
        ])
        set_cell_text(cells[COL_PETROL_COST], format_currency(entry['petrol_cost']))
    
    # মোবাইল
    if entry['mobile_recharge'] > 0:
        set_cell_text(cells[COL_MOBILE], format_currency(entry['mobile_recharge']))
    
    # DA
    if entry['da_amount'] > 0:
        set_cell_text(cells[COL_DA], format_currency(entry['da_amount']))
    
    # মোট
    set_cell_text(cells[COL_TOTAL], format_currency(entry['total_cost']))
    
    # সাথে (ম্যানেজার বা মাসিক মিটিং)
    if entry['entry_type'] == 'MONTHLY_MEETING':
        bijoy_meeting = unicode_to_bijoy('মাসিক\nমিটিং')
        set_cell_text(cells[COL_WITH], bijoy_meeting)
    elif entry.get('manager_designation'):
        set_cell_text(cells[COL_WITH], unicode_to_bijoy(entry['manager_designation']))


def format_distributor_names(names: list, entry: dict) -> str:
    """পরিবেশকদের নাম বিজয়তে রূপান্তরিত করে ফরম্যাট করে"""
    if entry['entry_type'] == 'MONTHLY_MEETING':
        # Service center entry: গন্তব্য + ভাড়া বিবরণ
        venue = entry.get('venue', '')
        transport_desc = entry.get('transport_description', '')
        return unicode_to_bijoy(venue + '│\n' + transport_desc)
    
    # সাধারণ এন্ট্রি: প্রতিটি নামের আগে মেসার্স এবং শেষে │
    formatted = []
    for name in names:
        if not name.startswith('মেসার্স '):
            name = 'মেসার্স ' + name
        formatted.append(name + '│')
    return unicode_to_bijoy(' '.join(formatted))


def format_currency(amount: int) -> str:
    """মুদ্রা ফরম্যাট: 1357 → '1,357/-'"""
    if amount == 0:
        return ''
    formatted = f"{amount:,}/-"
    return formatted
```

def validate_odometer(start: int, end: int, previous_end: int | None) -> tuple[bool, str]:
    """ওডোমিটার রিডিং যাচাই করে"""
    if end < start:
        return False, "শেষ রিডিং শুরু রিডিংয়ের চেয়ে বড় হতে হবে।"
    if previous_end and start < previous_end:
        return False, f"শুরু রিডিং ({start}) পূর্ববর্তী শেষ রিডিংয়ের ({previous_end}) চেয়ে কম হতে পারবে না।"
    if end - start > 500:
        return False, "একদিনে ৫০০ কিমির বেশি ভ্রমণ সম্ভব নয়। পুনরায় যাচাই করুন।"
    return True, ""

def validate_petrol_liters(liters: float) -> tuple[bool, str]:
    if liters <= 0:
        return False, "পেট্রোলের পরিমাণ ০-এর বেশি হতে হবে।"
    if liters > 30:
        return False, "৩০ লিটারের বেশি পেট্রোল গ্রহণযোগ্য নয়।"
    return True, ""
```

### ১৬.১ বাংলা সংখ্যা গ্রহণ

Telegram-এ ব্যবহারকারী বাংলা সংখ্যা (১২৩) বা ইংরেজি সংখ্যা (123) উভয়ই ব্যবহার করতে পারবেন। ডেটাবেস ও গণনায় সর্বদা ইংরেজি সংখ্যা ব্যবহার করুন।

```python
def normalize_number(text: str) -> str:
    """বাংলা সংখ্যা ইংরেজিতে রূপান্তর করে"""
    bn_digits = '০১২৩৪৫৬৭৮৯'
    en_digits = '0123456789'
    return text.translate(str.maketrans(bn_digits, en_digits))
```

### ১৬.২ ডকুমেন্টে সংখ্যা ফরম্যাট

- **সিরিয়াল নম্বর:** দুই সংখ্যায় (০১, ০২, ... ২৪)
- **তারিখ:** DD/MM/YY (02/05/26)
- **ওডোমিটার:** সরাসরি (51833)
- **কিলোমিটার (মোট):** সরাসরি (88) — শুধু মিটিং এন্ট্রিতে "00"
- **লিটার:** পূর্ণ সংখ্যা (10, 43)
- **মুদ্রা:** কমা সহ + `/-` (1,357/-, 200/-)
- **মোট সারিতে গ্র্যান্ড টোটাল:** শুধু `/` শেষে (12,015/)

### ১৬.৩ SutonnyMJ ফন্ট ইনস্টলেশন নোটিশ

রিপোর্ট পাঠানোর সময় সর্বদা এই বার্তা যোগ করুন:
```
⚠️ ফাইলটি সঠিকভাবে দেখতে SutonnyMJ ফন্ট কম্পিউটারে ইনস্টল করতে হবে।
```

### ১৬.৪ একাধিক লাইনের সেল

লিটার/মূল্য কলামে দুটি পৃথক রান থাকে:
- রান ১: সংখ্যা (যেমন: "10")
- রান ২: "লিটার" বা "কি:মি:" (বিজয়-এনকোডেড)

XML-এ এটি দুটি `<w:r>` element হিসেবে ঢোকাতে হবে।

### ১৬.৫ খালি সেল

কোনো ডেটা না থাকলে সেলটি সম্পূর্ণ খালি রাখুন (blank `<w:t>`)। শূন্য মান (0) লেখবেন না।
